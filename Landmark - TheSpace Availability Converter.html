Applied Rules
✓
One CSV per Building, zipped
✓
Office/Unit Number ← Space Name
✓
Square footage ← Size (sq.ft.), rounded DOWN to nearest whole number
✓
Desk capacity ← Desks To
✓
Price per month ← Listing Price (Monthly), no £ or commas, rounded UP to nearest whole number
✓
Floor ← Floor column (0 → "Ground", -1 → "Basement", otherwise passed through)
✓
Available from ← Availability Date (dd/mm/yyyy → yyyy-mm-dd, future only; past/blank/"available now" = blank)
✓
Office position ← Room Type ("External" → "Window", "Internal" → "Internal")
✓
What's included ← "* [Office/Unit Number]"
✓
What's not included: blank
✓
Min term (months): default 3 | Max term (months): blank
✓
Number of additional rooms ← extracted from Comments if present, else blank
✓
Rows with a Status other than "Available" are skipped
