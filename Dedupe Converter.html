How deduplication works
1
Parses any format using the same smart column detection as Master Converter — handles tab-separated, space-separated, Excel, CSV, free text.
2
Converts each row to the standard 13-column format (price rounded up, sqm→sqft, position normalised, desk count inferred).
3
Builds a normalised key per row based on your chosen strategy. "Office 07" = "Office 7" = "07". Prefixes (Office, Suite, Unit, Room) are stripped. Leading zeros removed.
4
First occurrence of each key is marked unique ✓. All subsequent matches are marked as duplicates ✗ and show which row they duplicate.
5
"Download Unique CSV" exports only the clean deduplicated rows in the standard 13-column template format.
6
"All rows (with flag column)" adds a Duplicate column so you can review the flagged entries before deciding.
